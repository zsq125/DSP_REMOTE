## 3. 缺陷教训（D1–D6：根因 → 修法）

| # | 根因 | 修法 |
|---|---|---|
| **D1** | `savePairing()` 是 suspend，未落盘就 `start()`，服务内 `loadPairing()` 读到 null 早退 | `completePairing()` 改为**先 await 落盘 → 再 start → 再通知**；`onPairingSaved()` 允许补建 |
| **D2** | `if (!started) { started = true; startUp() }`：`started` **永不回退**，首次早退即永久失效 | **删除**一次性闸门，每次 `onStartCommand` 驱动**幂等**建连（不得重复建连，见 K3） |
| **D3** | `start()` 只在配对提交回调 ⇒ 已配对状态重启 App 后服务不启动、长连接不恢复 | 冷启动即读配对并幂等建连；未配对进 `WAITING_PAIRING`（**不是终局**） |
| **D4** | 仅 `Screen.DETAIL` 传 `onState`，列表页停在初值 ⇒ 恒显"未连接"，**掩盖真实故障** | 新增 `ConnectionStateBus`（订阅即回放快照），两页共同订阅 |
| **D5** | `armForegroundDeadline` 判 `if (!started)`，而该函数里 `started` 已置 true ⇒ **5s 保命兜底永不触发** | 到点**无条件**补调 `ensureForeground()` |
| **D6** | **扫码页从未实现**：`Screen` 枚举无 `SCANNER`，按钮只调 `requestCamera.launch(...)`；权限已授予时系统不弹框也不回调 ⇒ 点击毫无反应。**CameraX 依赖从未被调用**（Active Camera Clients 恒为 `[]`、logcat 无相机日志） | 新增 `ScannerScreen` + `Screen.SCANNER`；判定抽成**纯函数** `CameraPermissionGate`（未授权 ⇒ 请求权限；已授权 ⇒ **直接启动相机预览**）+ 权限状态参与重组 + 单测回归 |

D6 机器判据（真机，**必须点两次**）见 02 §11.4；D1–D4 回归入口 `node tests/regress/conn-defects/run.mjs`，守卫 K1/K2/K3/D4b 必须始终 PASS。

## 4. 测试会话污染事件与避免规则（**必须遵守**）

**事件**：开发自测用"真实新建会话 + 发 prompt"验证功能，在用户 DSH 目录留下 **126 个一次性会话**（**97 个跑了真实模型回合**，消耗 token）；一份"测试会话清单"用模糊匹配生成（`-like '*pro*'`，而 `project` 含 `pro`），**误把 7 个用户真实会话判为测试产物**——照它删会毁掉用户在其它项目的数据（PM 未用该文件，改以网关内建台账逐条核对后精确删除；用户会话经核对确认**未被污染**）。

**避免规则**：

1. **常规验证不得新建真实会话**：优先用 `DSH_RC_TEST_HOOKS=1` 门控钩子（`_test/busy`、`_test/echo-prompt`）与**只读回归**；确需新建时必须登记并清理。
2. **身份判定只认权威来源，禁止模糊/启发式匹配**：登记与清理**只以网关内建台账** `pc-gateway/.state/test-created-sessions.json` 为准（网关在 `POST /rc/v1/sessions` 成功后自动追加）。
3. **不得依据任何"清单文件"删除用户会话**（`tests/.evidence/created-sessions.json` 顶部已写明禁止依据它删除任何会话）。
4. **一次性 subagent 用完即清理**（其会话一经创建就留在 `~/.dsh`）。
5. 角色 subagent 一对一规则**未被违反**：只有开发、测试两个角色 subagent，上述 `delegationDepth=1` 条目是临时派生的一次性子 agent。

## 6. 环境坑（实测汇总）

- **PowerShell 5.1 以 GBK 解码 UTF-8** ⇒ 中文乱码并致误判（源码、`sfc` 输出均中招）；读 UTF-8 源文件用 read 工具、不用 `Get-Content`；`pc-gateway/*.ps1` 必须**纯 ASCII**（见 01 §9.4）。
- **`Start-Process -ArgumentList` 不给含空格参数加引号** ⇒ `--user-data-dir=...\Temp\User Data\x` 被截断为 `...\Temp\User`；含空格参数必须**整体内嵌引号**。
- **长驻进程（模拟器）必须与后台 job 解耦**（`Start-Process` 分离启动）：job 终止会把模拟器一起带走（`exit code 1` + `Wait for emulator … shutdown`）；启动前自检 `emulator -accel-check`。
- **百度输入法会向 hex 串追加字符**：token/哈希等 hex 串勿经输入法粘贴，须逐字符核对。
- **手机 USB 模式切换会导致 adb 掉线**：切模式后须重新 `adb devices` 确认在线。
