# DSH 手机远程控制 — 用户使用指南

> 版本：v1（对应接口规范 v1）；面向**使用者**。开发者文档见 `01-架构与接口规范-v1.md` 与 `pc-gateway/README.md`。

## 1. 它是做什么的

在 Android 手机上**查看并控制** PC 上的 DeepSeek Harness（DSH）任务：看任务/会话列表（含运行状态）、查看某任务的历史与实时输出、发指令、中断任务、新建任务。手机与 PC 走**局域网**（同一 Wi-Fi），首次通过**扫码配对**建立信任。

## 2. 前置条件

| 项 | 要求 |
|---|---|
| PC | Windows，已安装并**能正常运行** DSH（`dsh web` 可用） |
| 手机 | Android 8.0（API 26）及以上 |
| 网络 | **手机与 PC 连同一个 Wi-Fi/局域网**（硬要求；跨网络需自行做端口转发/内网穿透，不在本版范围） |
| PC 局域网 IP | 典型形如 `192.168.2.27`（见第 3 节，网关会自己选并打印） |

## 3. PC 端：启动网关

```powershell
cd <项目目录>          # 例如 F:\project\deepseekharness_remote_control
.\pc-gateway\start-gateway.cmd
```

> 为什么用 `.cmd`：本机 PowerShell 执行策略是 `RemoteSigned`，直接运行 `.ps1` 会被拒绝。
> `.cmd` 包装内部用 `-ExecutionPolicy Bypass` 调起脚本，**只影响该子进程**，不改系统设置。

启动成功后终端会打印：

1. **候选局域网地址列表**与**最终选中项**（★ 标记），例如：
   ```
   ✗ 192.168.125.1    VMware Network Adapter VMnet8  排除：虚拟网卡
   ★ 192.168.2.27     WLAN                           所在网段有默认路由
   => 选中 192.168.2.27（WLAN）
   ```
   多网卡机器若选错，可强制指定：`.\pc-gateway\start-gateway.cmd -LanHost 192.168.2.27`
2. **配对二维码（ASCII 艺术码）**——用手机 App 扫它。内容是一行 JSON，含 `host/port/token/fp`（`fp` 是令牌前 8 位，用于肉眼核对）。
3. 访问地址形如 `http://192.168.2.27:8765`。

停止：`.\pc-gateway\stop-gateway.cmd`。状态文件（排查时可看）：`pc-gateway\.state\gateway.json`（含 `host/port/token/fp/pid/startedAt`）。

> 网关会**另外启动一个 DSH 实例**（默认端口 3099）承载控制能力，**不影响你正在用的 DSH**（默认 3080）；你的配置与正在跑的会话都不会被改动。

## 4. 手机端：安装与配对

1. 把 APK 传到手机并安装（首次需允许"安装未知来源应用"）。产物路径：`android-app\app\build\outputs\apk\debug\app-debug.apk`
2. 打开 App → **配对页**：
   - **扫码**：对着 PC 终端的二维码；
   - **或手动输入**：`主机` = PC 局域网 IP（如 `192.168.2.27`），`端口` = `8765`，`令牌` = `pc-gateway\.state\token.txt` 的内容。
3. 配对成功后进入**任务列表**，App 通过长连接接收实时更新。**不需要每次扫码**：token 长期有效，仅在 token 轮换、App 数据被清除、host 变化时才需重新配对。

## 5. 日常使用

| 操作 | 位置 |
|---|---|
| 查看任务列表与运行状态 | 首页 |
| 打开某任务看历史 + 实时输出 | 点任务行 |
| 发送指令 | 任务详情页底部输入框 |
| 中断当前回合 | 任务详情页「中断」按钮 |
| 新建任务 | 首页「新建」 |
| 修改连接信息 / 保活设置 | 设置页 |

**建议在设置页完成两件事**（让连接在息屏后仍存活）：① 允许 App **忽略电池优化**（Doze 会冻结网络）；② 国产 ROM（小米/华为/OPPO/vivo 等）在系统设置里给本 App 打开**自启动**与**后台运行**——否则前台服务也可能被清理。

App 会显示连接状态（`已连接 / 连接中 / 等待重试 / 退避中 / 补发队列中 / 已断开`）。断网期间发出的指令会**保存在本地队列**（上限 200 条并持久化），网络恢复后按顺序自动补发，不会静默丢失。

## 6. 已知限制（请务必知悉）

1. **"逐字实时输出"只对手机自己发起/续跑的任务有效。** 对**PC 的 DSH GUI 里此刻正在跑**的会话，手机只能在该回合结束后收到**整条文本**，看不到逐字过程（该流式数据是 DSH 执行进程的内存内瞬态，网关在另一个进程里拿不到）。
2. **手机与 PC 必须同一局域网**；跨网络不可用。
3. **传输是局域网明文 HTTP + 令牌鉴权**，未启用 TLS。请勿在不可信网络中使用；令牌泄露等于 PC 任务控制权泄露，必要时用 App 的重置或删除 `pc-gateway\.state\token.txt` 后重启网关来轮换。
4. **真机专属项仍需你亲自确认**：开发期已在 Android 14 模拟器（AEHD + AVD `dsh_test`）与真机 HONOR ADT-AN00 上验证过连接建立、前台服务、Doze 保活与网络切换；但相机扫码、真实息屏、厂商自启动、TEE 密钥等只能由真机判定（见第 9 节）。

## 7. 连不上时的排查顺序

1. **看 PC 上选的 IP 对不对**：终端里的 ★ 地址应是形如 `192.168.2.x` 的真实局域网地址。若显示的是 VMware/VirtualBox 网段（如 `192.168.125.x`/`192.168.211.x`），用 `-LanHost <真实IP>` 重启网关。查真实 IP：PC 上 `ipconfig`，找 **WLAN / 以太网** 适配器的 IPv4。
2. **确认同一网段**：手机 Wi-Fi 的 IP 应是 `192.168.2.x`（与 PC 前三段一致）。
3. **手机浏览器先试**：打开 `http://<PC的IP>:8765/rc/v1/ping`，应返回类似 `{"v":1,"name":"...","pairRequired":true}` 的 JSON。
   - 打不开 → 网络/防火墙问题（见第 4 步）；能打开但 App 提示鉴权失败 → 令牌不对（重新扫码或核对 `token.txt`）。
4. **防火墙**：本机已存在放行 `E:\system\nodejs\node.exe` 入站 TCP 的规则，无需额外配置。换一台 PC 若第 3 步打不开，请为该 `node.exe` 放行入站，或直接放行 TCP `8765`。
5. **令牌被轮换过**：App 里重新配对（`pair/rotate` 后旧令牌立即失效）。
6. **端口被占**：启动脚本会明确报错而不是静默换端口；用 `stop-gateway.cmd` 停掉旧实例再启动。

## 8. 安全与隐私

- 网关只在局域网内监听，但**没有 TLS**，同一局域网内其他人拿到令牌即可控制你的 DSH 任务；
- 令牌存于 `pc-gateway\.state\token.txt`（PC 侧，明文文件）与 App 私有存储（手机侧，Android Keystore + AES-GCM 加密后落盘，磁盘上只有密文；密钥失效/换机会自动降级为"需重新配对"，不崩溃）；
- 配对与手输两条路径都会校验目标地址属于私有网段（`10/8`、`172.16/12`、`192.168/16`、`169.254/16`、`127/8`、`localhost`、Tailscale `100.64/10`）。**填公网 IP 会被拒绝**——明文 HTTP 下令牌随每个请求外发，连公网等于把 PC 控制权令牌发到互联网。`my-pc` / `my-pc.local` 这类局域网主机名仍可用。
- 不用时请 `stop-gateway.cmd` 关闭网关。

## 9. 需你真机确认的清单

> 自动化脚本已就绪：`tests/device/check.ps1`（13 步）、`tests/device/check-scan.ps1`（扫码专项）。APK：`android-app\app\build\outputs\apk\debug\app-debug.apk`（约 41.9 MB）。

| # | 项目 | 怎么验 |
|---|---|---|
| 1 | 安装 | `adb install -r app-debug.apk`（或手机直接点击安装） |
| 2 | 扫码配对 | 对着 PC 终端的 ASCII 二维码扫（**注意：首次点击只弹权限，授权后需再点一次**） |
| 3 | 手输配对 | 手填 IP + 端口 + token |
| 4 | 核心交互 | 任务列表 → 打开任务 → 发指令 → 看输出 → 中断 |
| 5 | **息屏保活** | 锁屏 10 分钟，解锁后应仍有更新且无需手动重连 |
| 6 | **Doze 下连接** | `adb shell dumpsys deviceidle force-idle` 后仍能收消息 |
| 7 | 通知 | `adb shell dumpsys notification`：应不可清除（ongoing）且高优先级 |
| 8 | **网络切换** | Wi-Fi ↔ 4G 切换，App 应自动重连 |
| 9 | 电池优化白名单 | `adb shell dumpsys deviceidle whitelist` 中应含本 App |
| 10 | 厂商自启动引导 | MIUI / EMUI / ColorOS 设置页能跳转 |
| 11 | **前台服务 5s 硬时限** | Robolectric 只能证明"`onStartCommand` 内同步调用"；**真实 5 秒时限需真机观察是否 ANR / 抛 `ForegroundServiceDidNotStartInTimeException`** |
| 12 | **AndroidKeyStore 真实加解密** | 单测用的是软件密钥替身；需真机确认 TEE 内生成/解密/失效降级正常 |
| 13 | **token 落盘形态** | `adb shell run-as com.deepseek.dshremote` 检索，磁盘上应是 `v1:<base64>:<base64>` 密文，**不得是明文 token** |

**第 11/12/13 项无法用代码审查替代**（运行时/硬件相关行为）。其余 1–10 项若第 11–13 通过，通常也会随之确认。
